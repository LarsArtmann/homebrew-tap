# LarsArtmann Homebrew Tap

Custom Homebrew tap for [LarsArtmann](https://github.com/LarsArtmann) CLI tools.

## Usage

```bash
brew tap LarsArtmann/tap
brew install <formula>
```

## Available Formulae

- `google-domain-detector` — detect Google Workspace / GCP usage for a
  domain list from public DNS alone (source build from release tags)

Formulae are automatically published by [GoReleaser](https://goreleaser.com) on each release.
